# Six-Axis Robotic Arm

## Why I'm building it

I'm seeking funding to build a large six-axis robotic arm. Previously, I had a Robot Arm MK2 Plus. After an incident, the arm broke, which made me think more seriously about upgrading it. I had already been considering an upgrade before that happened.

The main problems with my previous arm were its size, limited lifting strength and missed steps. I've spent a lot of time working on robotic arms, and I hope this new build will be a useful upgrade.

## The design

I plan to build the [six-axis robotic arm by Event Horizon Research](https://www.printables.com/model/742414-6-axis-robotic-arm), using the original mechanical design as a starting point and adapting the motor control.

I'm requesting funding for the motors, suitable drivers and other hardware needed to build it. I already own one NEMA17 motor that I hope to reuse, once its fit and specifications are checked.

The full build depends on funding. I'm currently planning it and haven't ordered the parts yet. I would really appreciate support to make it possible.
